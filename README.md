# 📊 WhatsApp Chat Analyzer (with Sentiment Analysis)

A data science project that analyzes WhatsApp chat exports and provides meaningful insights including user activity, message patterns, word usage, emoji analysis, timelines, and sentiment analysis. The project is also deployed as a web app using Streamlit.

## 🚀 Live Demo
👉 https://whatsapp-chat-analyzer-srv6ytoa2nzx75ciupekkq.streamlit.app/

## 🎯 Project Overview
This tool processes WhatsApp chat data and transforms it into structured insights. It helps understand communication behavior, emotional tone of conversations, and activity patterns using data analysis and NLP techniques.

## ✨ Key Features
- Total messages, words, and media count analysis  
- Most active users detection  
- Word frequency analysis  
- Emoji usage insights  
- Timeline (daily/monthly) activity tracking  
- Activity heatmap generation  
- Link detection in chats  
- 💬 Sentiment analysis (Positive / Negative / Neutral)

## 🛠 Tech Stack
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Streamlit (for deployment)  
- NLTK / TextBlob (for sentiment analysis)  
- Regex (for data cleaning)

## ⚙️ Workflow
1. Upload WhatsApp chat export (.txt file)  
2. Data cleaning and preprocessing  
3. Feature extraction (users, messages, timestamps)  
4. Sentiment analysis on messages  
5. Visualization of insights  
6. Deployment using Streamlit

## 📊 Key Insights
- Chat activity distribution over time  
- Most active participants  
- Emotional tone of conversations  
- Frequently used words and emojis  
- Peak activity hours

## 🌐 Deployment
This project is deployed using Streamlit Cloud and is accessible via web browser.
